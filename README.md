# 🧩 Neurocare — Landing Page (Projeto Interdisciplinar)

Projeto interdisciplinar entre Front-end e Empreendedorismo, com o objetivo de elaborar a landing page de uma startup em desenvolvimento: a Neurocare.

## 📌 Sobre o projeto

A Neurocare é uma plataforma que conecta pais, professores e profissionais de saúde para coordenar o suporte a crianças do espectro autista em momentos de crise. A atividade integrou conceitos de front-end (estrutura, estilização e apresentação visual) com conceitos de empreendedorismo (proposta de valor, validação e comunicação da ideia de negócio), resultando em uma landing page que apresenta a startup ao público.

## ✨ Seções da landing page

- 🏠 Apresentação da Neurocare e sua proposta de valor
- 👥 Público-alvo (pais, professores, profissionais de saúde)
- ⚙️ Como a plataforma funciona
- 📞 Chamada para ação / contato

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap5

## 🎯 Motivação

Projeto acadêmico interdisciplinar com o objetivo de praticar a construção de uma landing page alinhada à proposta de valor de uma startup real em desenvolvimento, unindo habilidades técnicas de front-end à comunicação de uma ideia de negócio.
